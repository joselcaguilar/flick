# Gesture glyphs

Custom SVG gesture glyphs for Flick. They use `currentColor`, rounded strokes, and no external icon font. Motion-capable gestures have a static silhouette first; animation is added by the UI with Reduce Motion fallbacks.

Included: point, circle clockwise/counter-clockwise, two-hand separate, thumbs up/down, pinch dial, swipes in four directions, and open palm.
